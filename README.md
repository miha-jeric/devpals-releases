---

DevPals coordinates the **Claude Code** and **Codex** CLIs you already use into a structured development workflow. Describe a feature in plain language. DevPals then:

1. turns it into a plan you approve;
2. implements it in your project;
3. reviews the work independently;
4. verifies it before it is marked complete.

## Features

- **Conversation-first workflow.** Plans, progress, tool activity and handoffs in a single timeline.
- **Configurable roles.** Planner, Developer and Tester, each powered by Claude or Codex and the model of your choice.
- **Independent review.** Work is reviewed and verified by a different role before completion.
- **Parallel development.** Features are built in isolated Git worktrees and integrated into your branch.
- **Changes view.** Shows a full diff of every change, and you can attach files to a request.
- **Rules and permissions.** You decide which commands agents may run.
- **Usage overview, project export and import.**
- **Slovenian and English interface.** Dark, light and system themes.
- **Automatic updates.**

## Requirements

- Windows 10 or 11 (x64).
- Claude Code and/or Codex CLI, installed and signed in with your own subscription.
- DevPals uses no API keys of its own. Your project data is processed only by the CLIs you use.

## Installation

Download `DevPals-x.y.z-Setup.exe` from the [latest release](../../releases/latest) and run it.

The installer is not yet code-signed. If Windows SmartScreen shows a warning, choose **More info → Run anyway**.

Installed copies update themselves from this repository; updates are applied when the app is closed.
